Trace任务怎么讲
Trace任务固定机器人基座，只训练右后腿的 RR_thigh 和 RR_calf 两个关节，其余关节保持默认位置。
参考轨迹是两条相差90°的正弦曲线：

- 幅值：±20°
- 最大参考角速度：35°/s
- 两个关节形成周期性的协调运动
  策略输入共12维，包括轨迹相位、目标关节偏移、跟踪误差、实际关节位置、关节速度和上一时刻动作；输出为两个关节动作。动作幅值为±20°，目标变化速度限制为60°/s。
  奖励以轨迹跟踪为主，同时惩罚关节速度过大、动作突变和力矩过大。因此目标不是单纯“让腿动起来”，而是在准确跟踪、运动平滑和能耗之间取得平衡。
  仿真频率为300 Hz，策略频率为50 Hz，每回合8秒。
  JCT任务怎么讲
  JCT目录中的独立脚本主要用于实验前的关节控制验证：
- 键盘控制或按关键帧自动运动；
- 显示腿部末端运动轨迹；
- 检查关节正负方向、零位和运动范围；
- 通过UDP把仿真关节偏移发送给真实电机；
- 比较仿真目标与真机实际响应。
  虽然脚本名中带有 ik_trace，但当前实现并没有求解逆运动学，而是直接控制大腿和小腿关节角。

本研究采用分层验证方法。首先通过JCT关节联调模块验证电机通信、关节方向、零位、限幅以及仿真到真机的映射关系，确保底层执行链路正确。随后在Trace任务中引入强化学习，使策略学习右后腿两个关节的周期轨迹跟踪。训练时以跟踪精度为主要目标，同时约束动作变化、关节速度和驱动力矩，从而获得兼顾精度和平滑性的控制策略。简单来说，JCT解决“控制链路是否正确”，Trace解决“策略能否学会准确、平滑地跟踪轨迹”。

三阶段关系

1. 单腿轨迹生成与联调
   首先验证电机方向、零位、运动范围以及仿真到真机的映射，排除底层控制问题。
2. 单腿轨迹强化学习跟踪
   在底层链路可靠的基础上，让策略学习右后腿两个关节的周期轨迹，验证跟踪精度和平滑性。
3. 四腿协调轨迹强化学习跟踪
   将单腿策略扩展到四条腿。策略仍只学习一组大腿和小腿基础动作，再按照
   FL/RR同相、FR/RL反相
   映射到八个关节，降低学习难度并形成类似对角步态的协调关系。
   答辩口述版
   本研究采用由简单到复杂的递进路线。第一阶段通过单腿关节轨迹实验完成电机方向、零位、限幅和Sim2Real映射验证；第二阶段引入PPO算法，实现右后腿两个关节的周期轨迹跟踪；第三阶段将单腿跟踪方法扩展到四腿系统，通过对角腿相位映射实现八个关节的协调运动。该过程验证了控制方法从单关节链路、单腿学习到四腿协调控制的可扩展性。
