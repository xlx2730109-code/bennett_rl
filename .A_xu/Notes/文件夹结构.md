## 任务和机器人配置关系

```text
assets/robots/bennett.py                     # 只定义机器人和任务专用默认姿态
tasks/manager_based/*/*_env_cfg.py           # 决定这个任务用哪个机器人配置
tasks/manager_based/*/__init__.py            # 决定 --task 的任务名
tasks/manager_based/*/agents/rsl_rl_ppo_cfg.py # 决定训练超参数和日志目录名
```

`bennett.py` 里建议用“任务专用别名”固定姿态，例如：

```python
BENNETT_SINGLE_LEG_RR_TRACE_CFG = BENNETT_CFG_V3
BENNETT_QUAD_VELOCITY_CFG = BENNETT_CFG_V3
```

这样每个任务只导入自己的配置，不需要每次训练前手动改 `BENNETT_CFG`。
